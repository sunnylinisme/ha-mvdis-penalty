# 更新紀錄

## 0.5.4

- 將驗證碼查詢的預設嘗試次數從 3 次降為 1 次，避免多人查詢或服務異常時在短時間內產生過多請求。
- 仍保留進階重試設定，只有確實需要時才由使用者手動提高。
- 連線逾時、網路或網站錯誤時，立即停止本輪其餘查詢並冷卻 30 分鐘，再自動重試，避免同一來源 IP 連續失敗。
- 移除隱藏的 HTTP 自動重試，並縮短連線逾時；網頁介面會顯示冷卻原因與自動重試時間。

## 0.5.3

- 儲存 Add-on 設定後，會在約 5 秒內自動重新驗證並立即查詢，不必重新啟動或等待下次排程。
- 設定錯誤會指出是哪位查詢人及哪個欄位，網頁介面也會顯示修正方式，不再只留下空白畫面。

## 0.5.2

- 精簡常見問題，移除已不適用的舊版安裝時間與憑證相容性說明。

## 0.5.1

- 網頁介面改為顯示最近更新及下次排程更新時間，並移除容易誤解的自動更新說明。

## 0.5.0

- 將約 49 MiB 的 Python/OCR 執行相依套件與模型改為可跨版本重用的固定容器圖層；升級本版後，後續僅修改程式碼的更新不必重複下載這些大型圖層。
- 新增 `aarch64` 映像，除 Intel/AMD 主機外也支援 64 位元 ARM Home Assistant OS。
- 加入 Home Assistant Supervisor 健康監控，並改為在 Home Assistant Core 啟動後再啟動查詢服務。
- 記住曾回報過的罰單識別碼，避免紀錄暫時消失後重新出現時重複通知。
- 驗證臺灣身分證檢查碼及民國出生日期，能在查詢前發現輸入錯誤。
- 政府網站暫時發生連線或伺服器錯誤時，會進行有限次數的安全重試。
- 強化狀態檔的原子寫入、私密檔案權限與損毀檔案保留機制。
- 修正「應繳日期」可能被誤判為金額的情況。
- 更新 Requests 至已修補安全性問題的版本。

## 0.4.0

- 新增由 Home Assistant Ingress 保護的內建查詢頁面，不對區域網路開放連接埠。
- 可查看每位查詢人的狀態、完整罰單表格欄位、未繳筆數與辨識金額。
- 新增立即查詢及不建立假資料的測試通知。
- 將查詢錯誤分類為驗證碼、身分資料、網站格式、逾時、網路及服務錯誤。
- 從設定移除查詢人後，會自動清理其舊實體及群組。
- 先前有未繳紀錄而本次結果清空時，會建立確認提醒並觸發 `mvdis_penalty_cleared`。

## 0.3.1

- 修正監理服務網將驗證碼錯誤訊息放在 JavaScript 中時，Add-on 未自動重試而顯示解析錯誤的問題。
- 為每位查詢人自動建立群組實體，方便在 Home Assistant 中集中查看及搜尋其五個罰單實體。

## 0.3.0

- 支援最多 5 位查詢人，每人有獨立實體、查詢基準、錯誤狀態與新罰單通知。
- 保留主要查詢人的既有實體 ID，原有儀表板與自動化不需修改。
- 精簡本機 OCR 執行環境，只保留實際使用的模型與相依套件，並移除容器內多餘的虛擬環境與位元碼，大幅縮小安裝及更新下載量。
- 多人查詢依序執行，單一查詢人失敗不會阻擋其他人。

## 0.2.3

- 改用 GitHub Container Registry 預先建置映像檔。
- Home Assistant 安裝與更新時不再於本機安裝 Python 與 OCR 相依套件。

## 0.2.2

- 將專案首頁、Add-on 說明、設定提示與更新紀錄改為繁體中文。
- 補上安裝、更新、通知及常見問題說明。

## 0.2.1

- 避開目前 TWCA 根憑證與 Python 嚴格 X.509 模式的相容性問題。
- 仍保留憑證授權單位、主機名稱、有效期限及簽章驗證，未使用不安全的 TLS 設定。

## 0.2.0

- 將專案整合為單一 Home Assistant Add-on，不再需要 HACS。
- 透過 Home Assistant 內部 Core API 直接建立五個實體。
- 發現新紀錄時觸發 `mvdis_penalty_new_case` 並建立永久通知。
- 移除本機回送 API 與不必要的主機網路權限。

## 0.1.1

- 加入 HACS 驗證所需的整合品牌圖示。
- 加入 HACS 驗證所需的儲存庫主題。

## 0.1.0

- 首次實驗版，支援 Home Assistant OS `amd64`。
- 加入監理服務網驗證碼本機辨識與排程查詢。
- 提供舊版 HACS 整合使用的本機 JSON API。

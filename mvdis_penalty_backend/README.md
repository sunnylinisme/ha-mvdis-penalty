# Taiwan MVDIS Penalty Backend

Local `amd64` query and CAPTCHA OCR backend for the Taiwan MVDIS Penalty HACS
integration. The service binds only to `127.0.0.1:8099` on the Home Assistant
host. It does not expose a LAN port and does not use an external OCR service.

Install the HACS integration from the same repository after this add-on is
configured and running.
